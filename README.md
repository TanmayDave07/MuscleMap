# Fitness Exercises App

A React app to search and explore fitness exercises. Browse by body part, view GIF demos, and watch related YouTube videos for proper form.

![Home Page](./screenshots/home.png)

## Tech Stack

- React 18
- Tailwind CSS
- RapidAPI (ExerciseDB + YouTube Search)

## Setup

```bash
git clone https://github.com/your-username/fitness-exercises-app.git
cd fitness-exercises-app
npm install
```

Create a `.env` file:

```
REACT_APP_RAPID_API_KEY=your_key_here
```

Get your API key from [RapidAPI](https://rapidapi.com/) by subscribing to [ExerciseDB](https://rapidapi.com/justin-WFnsXH_t6/api/exercisedb) and [YouTube Search](https://rapidapi.com/h0p3rwe/api/youtube-search-and-download).

```bash
npm start
```

## Features

- Search exercises by name
- Filter by body part
- Exercise cards with GIF demos
- Detailed exercise page with instructions
- Related YouTube videos
- Responsive layout
